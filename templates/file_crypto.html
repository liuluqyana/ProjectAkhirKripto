Dekripsi paket soal

Unggah berkas .kgp, lalu berikan token secara langsung atau unggah gambar Logo UPN agar token diekstrak otomatis.

Format berkas KGP2

OffsetUkuranIsi
04 byteMagic header KGP2
41 byteVersi format (1)
54 byteIterasi PBKDF2-HMAC-SHA256 (uint32)
916 byteSalt acak
2512 byteNonce ChaCha20-Poly1305
37sisaCiphertext + tag 16 byte (nama berkas + isi). Header menjadi AAD.
